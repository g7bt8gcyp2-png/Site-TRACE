# TRACE — site da marca

Site interativo da **TRACE**, marca própria de periféricos gamer da Inicial Games.

- **Intro animada:** a cobra rasteja no escuro, brilha em roxo, dá uma volta e se enrola no T, revelando o logo TRACE.
- **Slogan:** "Precisão em cada movimento" acende palavra por palavra conforme a rolagem.
- **Linhas Standard / Skill:** alternância entre as linhas, filtro por categoria e cards clicáveis com descrição, especificações e preço médio.

Site estático (HTML, CSS e JS puros, sem build). Para ver localmente:

```bash
python3 -m http.server 8000
# abra http://localhost:8000
```

Também pode ser publicado direto no GitHub Pages (Settings → Pages → branch e pasta `/`).

> Proposta acadêmica: produtos, imagens e especificações são conceituais.
